# Professor Byte - Custom Ollama Model

## Overview

Professor Byte is a custom AI assistant built using Ollama. The model is based on the `llama3.2:3b` foundation model and customized through a Modelfile to create a unique personality.

Unlike the default assistant, Professor Byte behaves like an experienced Artificial Intelligence professor who teaches concepts in a friendly, encouraging, and easy-to-understand manner.

---

## Model Information

- **Base Model:** llama3.2:3b
- **Custom Model Name:** prof-byte
- **Platform:** Ollama
- **Configuration:** Modelfile

---

## Personality

Professor Byte is:

- An experienced AI professor
- Calm and patient
- Encouraging and supportive
- Uses simple real-world analogies
- Explains concepts step-by-step
- Ends responses with practical teaching tips

The goal was to create a model with a consistent identity instead of the default AI assistant personality.
